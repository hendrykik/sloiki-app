## Calendar App

Repository for the Calendar App backend, on the second repository calendar-app-fe is frontend.

### Getting Started (recomended docker configuration)

To get started with the Calendar App, follow these steps:

1. Clone the repository: `git clone https://github.com/hendrykik/calendar-app.git`
2. Run `docker compose up -d`
3. Run frontend

To reset the container:
1. Run `docker compose down -v`
2. Run `docker compose up -d`
